Minecraft Texturizer

Verwandle ein beliebiges Bild in ein Mosaik aus Minecraft-Texturen — komplett im Browser.

1. Eingangsbild

Eingangsbild Klicken oder hierher ziehen (PNG / JPG / WEBP)

Du kannst auch im Perlin Studio ein Bild oder eine Animation generieren und an den Texturizer übergeben.

2. Atlas

Textur-Atlas Optional — Standard-Atlas wird geladen, falls leer.

3. Parameter

Perlin-Parameter

t — Zeitkoordinate (Live)

Animation

Der Texturizer-Tab teilt sich Atlas + Mosaik-Parameter mit diesem Studio. Stelle dort Output-Breite, Block-Pixelgröße usw. ein, bevor du eine texturisierte Animation startest.

Ergebnis

Lade ein Eingangsbild und klicke „Mosaik generieren".

Atlas-Palette anzeigen
Vanilla JS, kein Backend. Aus dem alten Hobbyprojekt _archiv/texturizer.ipynb + _archiv/perlin_noise/.
